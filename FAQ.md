# FAQ

**Does my code leave my computer?**
No. Your files, project memory and logs stay on your computer. The server only receives your key, the name of the path or tool you ask for, the version and the language.

**What happens if I stop my subscription?**
CIRCÉ goes on standby. The served method and the signed tools stop, but the guard stays active. What you produced with CIRCÉ stays yours.

**On how many computers can I use it?**
3 computers per key.

**Which systems?**
Windows 10/11, macOS and Linux, with Claude Code on a paid Claude plan and Python 3.9 or newer. The clean-machine tests run on Windows. On macOS and Linux, the reflexes are tested through `sh` in the automated tests.

**Will it block my work?**
No. By default it refuses only 3 catastrophic moves: format a disk, wipe a drive root, wipe your home folder. Everything else is proposed, and you choose what to turn on.

**Can I get a refund?**
Yes, in full, within 14 days. Write to contact@cdow.fr with the e-mail used for your purchase.

**How do I install it?**
Follow the [install guide](https://cdow.fr/en/installation). You paste one request into Claude Code, and it does each step with you.

**Where do I report a bug?**
In this repository's [issues](../../issues/new/choose). Never paste your key there.
